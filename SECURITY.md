# Política de segurança

## Escopo

Este é um site estático publicado pelo GitHub Pages. Ele não possui formulários, autenticação, banco de dados ou API própria.

## Reporte responsável

Se identificar uma vulnerabilidade no conteúdo, no repositório ou na configuração de publicação, não publique detalhes em uma issue. Envie uma descrição objetiva para `comercial@sollarecia.com.br`, incluindo passos de reprodução e impacto observado.

## Controles adotados

- Publicação somente a partir da branch `main` protegida.
- Sem execução de JavaScript no site publicado.
- Sem segredos, tokens ou credenciais versionados.
- Proteção contra force-push e exclusão da branch de publicação.
- Proteções de segredo do GitHub habilitadas.
- HTTPS obrigatório assim que o certificado do domínio estiver emitido pelo GitHub Pages.

## Limites

Nenhum serviço na Internet é impenetrável. A segurança também depende da proteção da conta GitHub administradora, incluindo senha exclusiva, autenticação de dois fatores e revisão periódica de dispositivos e tokens autorizados.
