# Sollar Representações — site institucional

Site estático para apresentar as marcas representadas e direcionar aos catálogos oficiais compartilhados no Linktree da Sollar.

- Site: `https://sollarecia.com.br`
- Instagram: `https://www.instagram.com/sollar.representacoes/`
- Linktree: `https://linktr.ee/sollar.representacoes`

## Publicação

Hospedado no GitHub Pages. O arquivo `CNAME` informa o domínio personalizado.

## DNS necessário no Registro.br

Preservar os registros MX da Zoho. Para o site, apontar os registros A do domínio raiz aos IPs do GitHub Pages e o `www` para `<usuário>.github.io`.
